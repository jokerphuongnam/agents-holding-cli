# agents-holding 料金表（クレジット）

[English](../PRICING.md)

クレジットプラン、各種上限、操作ごとのコスト、アップグレード方法をまとめています。アプリ内での支払いはありません。アップグレードは **key id** を添えてオーナーにご連絡ください。

お使いのマシンで現在のプランを確認: `holding billing` · `holding usage` · `holding key show` (表示されるのは key id のみで、シークレットは表示されません)

## スタッフ上限（会社ごと）

1 社のロスターに登録できるスタッフの最大数です（CEO を含む）。スタッフの追加・異動・割り当て、移行、新しい会社の作成時に適用されます。オーナーキーには上限がありません。

| プラン | 最大スタッフ数 / 社 |
|---|---:|
| free | 5 |
| starter | 10 |
| lite | 15 |
| pro | 25 |
| marketplace | 25 |
| power | 40 |
| max | 60 |
| ultra | 無制限 |
| enterprise | 無制限 |

クレジットプラン**なし**の旧キー：trial 20 · monthly 30 · yearly 50 · それ以外は 30。

上限に達すると次のように表示されます：*「プラン X のスタッフ上限 N 人に達しました。先にスタッフを解雇するか、プランをアップグレードしてください。」*

## デバイス上限（マシン）

| 項目 | 値 |
|---|---|
| キーごとの既定値 | **1** 台 |
| オーナーが設定できる範囲 | キーごとに **1〜50** 台 |
| マシン上で作成する Free キー | マシン 1 台につき Free キーは **1 つ** |

デバイス枠が足りない場合は、オーナーに上限の引き上げを依頼してから新しいマシンで再度お試しください。使用数/上限は `holding key show` で確認できます。

## 操作ごとのクレジットコスト

クレジットを消費するのは、作業を生み出す以下の操作だけです。それ以外（heartbeat、リアルタイム同期、status、billing、inbox の一覧、key、admin、ほとんどの CLI コマンド）は**無料**です。

| 操作 | クレジット |
|---|---:|
| エージェント実行 (`next_action`) | **2** |
| `advance` | 1 |
| `jira_ops` | 1 |
| `staff_brief` | 1 |
| `record_artifact` | 1 |
| `assign` (次を含む： `holding task set …`) | 1 |
| `ceo` | 1 |
| `inbox_post` / `inbox_reply` | 1 |

**モデルのトークンがクレジットとして課金されることはありません。**

### アップロード（Jira 添付 / Figma エクスポート / Confluence）

**1 ファイルにつき 1 クレジット、最初の 5 MB を超える 10 MB ごとに 1 クレジット追加**、**1 ファイルあたり最大 5 クレジット**。

例: 0.4 MB → 1 · 25 MB → 3 · 300 MB → 5.

ファイルはお使いのマシンから Jira・Confluence・Figma へ直接送られます。サーバーはクレジット計算のためにサイズだけを測ります。

## 追加クレジットの購入（プラン変更なし）

プランを変えずにクレジットを追加できます。種類は 3 つです：

| 種類 | しくみ |
|---|---|
| `expire` | 現在のプラン期間の終了とともに失効 |
| `next` | すぐに使えます。期間終了時の残りはいったんロックされ、次の期間が始まるとロック解除されて加算されます |
| `keep` | 使い切るまで残ります |

価格：key id を添えてオーナー（phuongnamp99@gmail.com）にお問い合わせください。

## アップグレード・クレジット追加

1. **key id** を確認します（シークレットキーは絶対に送らないでください）：`holding key show`、または `holding billing` / `holding usage` の「To upgrade」行。
2. key id と希望のプラン（または今期に必要な追加クレジット）を**オーナー**（**phuongnamp99@gmail.com**）に送ります。
3. **アプリ内決済はまだありません。** 決済に対応した後も同じ流れで使えます。この料金表は引き続きここで確認できます。

クレジット切れ・キーの期限切れの場合：Jira Listener が停止し、更新またはクレジット追加のためにオーナーへ連絡するよう案内します。
