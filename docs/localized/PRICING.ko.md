# agents-holding 요금표 (크레딧)

[English](../PRICING.md)

크레딧 플랜, 각종 한도, 작업별 비용, 업그레이드 방법을 정리했습니다. 앱 내 결제는 없습니다. 업그레이드하려면 **key id**와 함께 오너에게 연락하세요.

내 컴퓨터에서 현재 플랜 확인: `holding billing` · `holding usage` · `holding key show` (key id만 표시되며 시크릿은 절대 표시되지 않습니다)

## 작업별 크레딧 비용

작업을 만들어 내는 아래 작업만 크레딧이 듭니다. 그 밖의 모든 것(heartbeat, 실시간 동기화, status, billing, inbox 목록, key, admin, 대부분의 CLI 명령)은 **무료**입니다.

| 작업 | 크레딧 |
|---|---:|
| 에이전트 실행 (`next_action`) | **2** |
| `advance` | 1 |
| `jira_ops` | 1 |
| `staff_brief` | 1 |
| `record_artifact` | 1 |
| `assign` (포함: `holding task set …`) | 1 |
| `ceo` | 1 |
| `inbox_post` / `inbox_reply` | 1 |

**모델 토큰은 절대 크레딧으로 청구되지 않습니다.**

### 업로드 (Jira 첨부 / Figma 내보내기 / Confluence)

**파일당 1크레딧, 처음 5 MB를 넘는 10 MB마다 1크레딧 추가**, **파일당 최대 5크레딧**.

예시: 0.4 MB → 1 · 25 MB → 3 · 300 MB → 5.

파일은 내 컴퓨터에서 Jira, Confluence, Figma로 바로 전송됩니다. 서버는 크레딧 계산을 위해 크기만 측정합니다.

## 추가 크레딧 구매 (플랜 변경 없음)

플랜을 바꾸지 않고 크레딧을 충전할 수 있습니다. 종류는 세 가지입니다:

| 종류 | 방식 |
|---|---|
| `expire` | 현재 플랜 기간이 끝나면 함께 소멸 |
| `next` | 바로 사용 가능; 기간이 끝날 때 남은 양은 잠겼다가 다음 기간이 시작되면 잠금 해제되어 더해집니다 |
| `keep` | 다 쓸 때까지 유지 |

가격: key id와 함께 오너(phuongnamp99@gmail.com)에게 문의하세요.

## 업그레이드 / 크레딧 추가

1. **key id**를 확인합니다(시크릿 키는 절대 보내지 마세요): `holding key show` 또는 `holding billing` / `holding usage`의 "To upgrade" 줄.
2. 원하는 플랜(또는 이번 기간에 필요한 추가 크레딧)과 함께 key id를 **오너**(**phuongnamp99@gmail.com**)에게 보냅니다.
3. **아직 앱 내 결제는 없습니다.** 결제가 도입되어도 같은 흐름으로 업그레이드하며, 이 요금표는 계속 여기서 확인할 수 있습니다.

크레딧 소진 / 키 만료 시: Jira Listener가 멈추고 갱신이나 크레딧 추가를 위해 오너에게 연락하라고 안내합니다.
